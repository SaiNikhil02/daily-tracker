# Daily Schedule Tracker

A beautiful, Notion-inspired daily schedule tracker that helps you track your tasks, maintain discipline, and analyze your productivity patterns.

## Features

- ✅ **Time Slot Management** - Create and manage daily time slots with tasks
- 📊 **Scoring System** - Track completion with partial scoring (0-100%)
- ⏰ **Missed Task Detection** - Automatically marks tasks as missed when time passes
- 💭 **Reflections** - Add "why not done?" reflections for incomplete tasks
- 🔥 **Streak Tracking** - Track consecutive days with 80%+ completion
- 📅 **Mini Calendar** - Visual calendar view with color-coded completion rates
- 📋 **Copy Yesterday** - Quickly duplicate yesterday's schedule
- 📈 **Weekly Analysis** - Review partial, undone, and missed tasks from the past week
- 💾 **Local Storage** - All data stored locally in your browser

## Getting Started

1. Open `index.html` in your web browser
2. Click "+ New" to add time slots
3. Mark tasks as Done, Not Done, or Partial throughout the day
4. View your score and streak in the header
5. Use the mini calendar to navigate between days

## Deployment

This is a static website that can be deployed to any hosting service. Here are some options:

### GitHub Pages (Free)

1. Create a new GitHub repository
2. Push all files to the repository
3. Go to Settings → Pages
4. Select main branch and `/root` folder
5. Your site will be live at `https://yourusername.github.io/repository-name`

### Netlify (Free)

1. Sign up at [netlify.com](https://netlify.com)
2. Drag and drop the folder or connect to GitHub
3. Your site will be live instantly

### Vercel (Free)

1. Sign up at [vercel.com](https://vercel.com)
2. Import your repository or drag and drop
3. Deploy with one click

### Manual Deployment

Upload all files (`index.html`, `style.css`, `script.js`) to any web hosting service.

## Browser Support

Works in all modern browsers (Chrome, Firefox, Safari, Edge).

## Data Storage

All data is stored locally in your browser's localStorage. Your data stays private and never leaves your device.
